# ⚡ tui-task-manager

Полноценный терминальный монитор задач (TUI Task Manager) на **Rust** (`ratatui` + `crossterm` + `sysinfo`) с полной поддержкой управления **мышью** и клавиатурой, группировкой приложений, деревом процессов и возможностью закрывать/замораживать приложения.

## ✨ Основные возможности

1. **Полная поддержка мыши (Click / Double-Click / Right-Click / Hover / Scroll)**:
   - **Клик ЛКМ по вкладкам** (`Процессы и Приложения`, `ЦП и Память (Графики)`, `Диски и Сеть`) и кнопкам управления.
   - **Клик ЛКМ по заголовкам колонок** таблицы (`PID`, `Приложение / Процесс`, `Юзер`, `Статус`, `CPU %`, `MEM %`, `Память`, `Чтение/с`, `Запись/с`, `Команда`) для сортировки по возрастанию/убыванию (`▲` / `▼`).
   - **Одиночный клик ЛКМ** по строке выбирает процесс; **двойной клик ЛКМ** открывает диалог закрытия / выбора сигнала.
   - **Правый клик (ПКМ)** по процессу открывает подробный инспектор процесса (`PID`, `PPID`, `RSS`, `Virtual`, `I/O`, `Exe`, `CWD`, `Cmd`) с быстрыми кнопками завершения.
   - **Прокрутка колёсиком мыши** вверх/вниз по таблице процессов.
   - **Подсветка при наведении (Hover)** на кнопки, заголовки колонок и строки таблицы.

2. **Закрытие приложений и управление процессами**:
   - Поддержка сигналов:
     - `SIGTERM (15)` — мягкое корректное закрытие приложения.
     - `SIGKILL (9)` — принудительное завершение зависшего процесса.
     - `SIGINT (2)` — прерывание (`Ctrl+C`).
     - `SIGSTOP (19)` — заморозка / приостановка процесса.
     - `SIGCONT (18)` — возобновление работы процесса.
     - `SIGHUP (1)` — перезагрузка конфигурации / закрытие терминала.
   - Опция **«Завершить вместе со всеми дочерними процессами»** для закрытия всего дерева процессов.
   - Режим **«Приложения (g)»**: объединяет многопроцессные программы (браузеры, IDE, мессенджеры) в одну строку с суммарным потреблением ЦП/ОЗУ и позволяет закрыть всё приложение одним действием.

3. **Мониторинг ресурсов в реальном времени**:
   - **Сводная панель**: общая загрузка ЦП и ядер, использование RAM и Swap, `Load Average`, `Uptime`, текущая скорость сети (`↓ RX/с`, `↑ TX/с`).
   - **Вкладка 2 (Графики и ЦП)**: история загрузки процессора и памяти (`Sparkline`) + детальные шкалы загрузки и частоты каждого потока ЦП.
   - **Вкладка 3 (Диски и Сеть)**: таблица примонтированных разделов с индикаторами заполненности и таблица сетевых интерфейсов с трафиком в реальном времени.

## 🚀 Сборка и запуск

```bash
cargo run --release
```

Или запуск скомпилированного бинарного файла:

```bash
./target/release/tui-task-manager
```

## ⌨ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `ЛКМ` / `Двойной клик` / `ПКМ` | Выбор элемента / Открытие окна закрытия / Подробности процесса |
| `x` / `Delete` | Завершить выбранное приложение (`SIGTERM`) |
| `k` / `F9` | Принудительно убить процесс (`SIGKILL`) |
| `S` | Открыть меню выбора любого сигнала |
| `s` | Мгновенно приостановить / возобновить процесс (`SIGSTOP` / `SIGCONT`) |
| `Enter` / `i` | Инспектор подробной информации о процессе |
| `/` или `f` | Поиск / фильтрация по имени, команде, пользователю или PID |
| `t` | Переключить режим дерева процессов (`Tree View`) |
| `g` | Переключить группировку процессов по приложениям (`App Grouping`) |
| `u` | Показать только процессы текущего пользователя |
| `K` | Скрыть / показать потоки ядра |
| `1` / `2` / `3` / `Tab` | Переключение вкладок |
| `Space` / `p` | Пауза / возобновление обновления данных |
| `+` / `-` | Изменить интервал обновления (`250 мс` — `5000 мс`) |
| `?` / `F1` / `h` | Открыть окно справки |
| `q` / `F10` | Выход |
